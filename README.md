This is the code for the SWE app. 
We are trying to make a progressive web app that allows SWE members to see upcoming events, track their points and past events attended,
and connect with SWEsters!

When updating .js files you will need to change the staticCacheName and dynamicCacheName versions in order to see the results. This 
is because the files are stored to be accessible offline and if you don't update the version you will see the old cached file. Sometimes
after updating the version you have to relaunch the PWA a few times to see the results.
